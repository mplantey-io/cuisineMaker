# Atelier Cuisine

Prototype d'outil de conception de cuisine paramétrique : pièce en polygone libre,
catalogue de meubles/électroménager/ouvertures, plans de travail à coins arrondis,
vue 2D façon plan bleu, vue 3D interactive, export plan pro (SVG), export 3D (GLTF),
export liste de matériel (CSV) et export/import de projet (JSON).

## Démo en ligne
https://mplantey-io.github.io/cuisineMaker/

## Développement local
```
npm install
npm run dev
```

## Build (déployé dans docs/ pour GitHub Pages)
```
npm run build
```
